## System updates

1. Log in: `ssh root@SERVER_URL`
2. Install the updates:
   ```bash
   apt-get update && apt-get upgrade -y
   ```
3. Read the output:
   - **`containerd.io` is updated**: Docker restarts, and with it every container. Plan a short downtime.
   - **"The following packages have been kept back"**: these need new dependencies. Install them by name:
     ```bash
     apt install PACKAGE_NAME …
     ```
4. Remove packages nothing needs any more:
   ```bash
   apt autoremove -y
   ```
5. Reboot if the system asks for it (`reboot`), then log in again.
6. Check that the containers are back: `docker ps`

## deploy.party updates

```bash
cd /var/opt/deploy-party
sh update.sh
docker ps
```

Details and the steps older installations need once: [Updates](../4.updates.md).

## Disk space

Builds leave images and build cache behind. When the disk fills up:

```bash
df -h
docker system prune
```

## Quick health check

```bash
free -m                         # memory
df -h                           # disk
top                             # CPU
lsof -i -P -n | grep LISTEN     # ports in use
docker ps                       # containers
```

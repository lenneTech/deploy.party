## Stacks and services

```bash
docker stack ls                     # all stacks
docker stack ps STACK_NAME          # current and past tasks of a stack
docker service ls                   # all services
docker service logs SERVICE_NAME    # logs of a service across restarts
```

## Containers

```bash
docker ps                               # running containers
docker logs CONTAINER_ID                # logs of a container
docker logs --tail 100 CONTAINER_ID     # the last 100 lines
docker logs -f CONTAINER_ID             # follow the log
```

## Configuration of deploy.party

```bash
cd /var/opt/deploy-party
ls -al
```

`.env` holds the configuration and its secrets, `docker-compose.yml` and `docker-compose.traefik.yml` the two stacks.
Do not print `.env` on a shared screen or into a ticket.

## System

```bash
free -m                             # memory
df -h                               # disk usage per partition
top                                 # CPU and processes
lsof -i -P -n | grep LISTEN         # ports in use
```

## Clean up

```bash
docker system prune                 # stopped containers, unused networks, dangling images and build cache
```

`docker system prune` asks before it deletes. Add `-a` only if you also want to remove every image no container uses;
the next build or deploy then pulls them again.

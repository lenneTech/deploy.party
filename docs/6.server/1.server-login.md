---
title: Server login
description: Log in to a deploy.party server and read what the login screen tells you about its state.
navigation:
  icon: i-lucide-log-in
---

```bash
ssh root@SERVER_URL
```

Use an SSH key, not a password. Depending on the provider, the login screen shows the state of the system:

- **Pending updates** and **pending security updates**: packages waiting for an update, see
  [Maintenance](./4.maintenance.md).
- **System restart required**: an update needs a reboot.
- **Zombie processes**: processes that ended without being cleaned up.

Check these before you change anything on the server.

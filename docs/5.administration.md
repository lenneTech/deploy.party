All commands run on the server as root, in `/var/opt/deploy-party`.

## Restart deploy.party

```bash
cd /var/opt/deploy-party
sh reconfigure.sh
```

The script removes the `deploy-party` stack and deploys it again with the current `.env`.

## Restart Traefik

```bash
docker stack rm traefik
```

Wait until no Traefik container shows up in `docker ps` any more, then:

```bash
cd /var/opt/deploy-party
export $(cat .env | grep -v '#' | awk '/=/ {print $1}') && docker stack deploy -c docker-compose.traefik.yml traefik
```

While Traefik is down, no application on the server is reachable.

## Logs

```bash
docker ps                                   # find the container
docker logs --tail 100 CONTAINER_ID         # the last 100 lines
docker service logs deploy-party_api        # the API service across restarts
```

The logs of your own containers are also in the UI of deploy.party. More commands in
[Docker commands](./6.server/3.docker-commands.md).
